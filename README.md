# Trend Jr — Marketplace Frontend (React + Vite + Tailwind CSS)

A modern, responsive e-commerce marketplace storefront built in **JavaScript (JSX)** with **React 18**, **Vite**, **Tailwind CSS**, and **Lucide React** icons.

## Quick Start

```bash
npm install
npm run dev
```

Then open the local URL printed in your terminal (usually `http://localhost:5173`).

## Build for Production

```bash
npm run build
npm run preview
```

## Included Features
- **Top Utility & Promo Bar**: Interactive Free Shipping, Buyer Protection, Weekly 10% Coupon (`TRENDJR10`), and Order Tracking modals.
- **Sticky Marketplace Header**: Multi-column Category Mega-Menu, live search with recent & trending suggestions, and an interactive **Search by Image** modal.
- **Editorial Bento Hero & Category Strip**: Quick category filtering and one-click promo claim.
- **Live Flash Deals Carousel**: Real-time countdown timer, claimed-stock progress bars, and quick add-to-cart.
- **Discovery Product Grid**: Category filters, tabs (`For You`, `Best-Selling`, `New`, `Top Rated`), price filters, and sorting.
- **Product Detail Modal**: Image previews, variant selection, delivery timeline tracker, and instant cart/wishlist actions.
- **Slide-Out Cart & Wishlist Drawers**: Quantity controls, live promo code validation (`TRENDJR10` for 10% off), and simulated checkout flow.
- **Auth Modal & Mobile Bottom Navigation**: Full responsive layout for desktop, tablet, and mobile.
